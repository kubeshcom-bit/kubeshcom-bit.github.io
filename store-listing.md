## Контентный рейтинг (анкета IARC) — подсказки для ответов
- Насилие: нет (в игре есть волк, который «убегает», крови нет)
- Реальные деньги / азартные игры: **нет** (колесо фортуны за игровые деньги, реальных ставок нет)
- Покупки внутри приложения: нет (в версии 1.0.1)
- Чат/общение между игроками: нет (только рейтинг с названиями ферм)
- Определение местоположения: нет
Ожидаемый рейтинг: 3+ / «Для всех».

## Раздел «Безопасность данных» (Data safety)
- Собираете ли данные? **Только если включено облако**: название фермы и анонимный ID (необязательно)
- Местоположение: не собирается
- Данные третьим лицам: не передаются (кроме рекламной сети, если подключите)
- Шифрование при передаче: да (https)
- Можно ли удалить данные: да (кнопка «Начать заново» + почта для облака)
- Если подключите рекламу: отметьте «Рекламный идентификатор» и перечислите рекламную сеть
